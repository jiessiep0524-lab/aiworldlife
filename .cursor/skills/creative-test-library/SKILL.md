# 冷受众素材测试资料库

这是两张思维导图的可执行版本，不是成熟账户的通用基准。判断素材前先读对应参考，不要用本库以外的 CTR、完播率或学习期标准替换它们。

- 短视频：[references/short-video.md](references/short-video.md)，原图 [references/short-video-source.png](references/short-video-source.png)
- 图片：[references/static-image.md](references/static-image.md)，原图 [references/static-image-source.png](references/static-image-source.png)

## 何时使用

冷受众上的非促销素材。冷受众指还不知道品牌、没访问过网站的人，包括兴趣受众、类似受众、泛受众。

暖受众（互动、访客、订阅、加购、放弃结账、已购买）数据不能拿来套这套门槛。

促销素材不走本流程，单独用一个广告系列投放。

## 使用前要有的数

- 素材类型：短视频或图片
- 保本 CPA（BEP CPA）。没有这个数时，只对照内容指标，花费门槛标成无法计算，不要按花费关停
- 本阶段样本量是否达到。短视频按播放，图片按展示
- 目标 ROAS 和目标 CPA。只在第三阶段使用

内容指标的具体百分比是教学示例。资料写明要按自己账号的实际数据调整，也会随时间和优化能力变化。用户没给出自己的门槛时，用参考文件里的示例，并标明「示例门槛」。

## 怎么判

1. 确认是冷受众、非促销。
2. 用播放或展示，以及花费相对保本 CPA 的倍数，确定处于第几阶段。样本没到该阶段，就写「样本不足」，不判输赢。
3. 初期只看内容指标。中期内容和转化一起看。后期看转化指标。
4. 内容指标和转化指标都「优秀」，才有资格进扩量组、投放大预算。
5. 内容很差仍可能有转化，原因可能是产品竞争力或运气。这种结果不能当成素材能扩量。
6. 数据差不要只关停。按该阶段动作分析原因、重做素材、再测。关停后的复查写进结论。

## 已准备的素材文件

本地素材库（只在用户自己的电脑上，当前环境读不到文件）：

`D:\0-工作\PND-视频素材\FB投流分类`

这是准备拿去投 Facebook 的视频文件。上面的短视频和图片参考是判断规则，不是这批文件本身。还没有这份目录的清单，所以不能按文件名分组或指定第一条测试用哪条片。

用户贴出文件夹结构、文件名，或把片子传到对话里之后，再把每条片标成冷受众非促销，并放进短视频测试的第一阶段。促销向的片子单独拿出，不进这套测试。

## 输出

每条素材给：阶段、情形（危险 / 观望 / 优秀，或第三阶段的盈亏平衡 / 明显盈利）、用到的指标原值、动作、还缺的数。不把示例门槛说成该账号已经验证过的标准。
